## ✨ Overview

**Fitnplus** is a personal UI/UX concept project for a modern fitness and health tracking application.

The project focuses on creating a simple, engaging, and visually premium experience where users can:

- Track daily health activity
- Monitor workouts and fitness metrics
- Review personal progress
- Receive personalized insights
- Participate in fitness challenges
- Compete with friends through leaderboards
- Manage connected fitness devices
- Control privacy and notification settings

The interface uses a **dark/light theme system**, glassmorphism, frosted borders, emerald-to-cyan gradients, subtle motion, and responsive layouts.

---

## 🎯 Project Goals

The main UX goals of Fitnplus are:

- Reduce cognitive load through clear information architecture
- Make important health metrics visible at a glance
- Create simple and intuitive navigation
- Encourage consistency through progress and challenges
- Build trust through privacy-focused design
- Maintain a consistent visual system across light and dark modes
